MarketForge simulates **208 crypto, forex and US stock instruments minute by minute**, each market on its real trading calendar, and writes candles from `m1` to `W1` as CSV, Parquet, Feather or pandas DataFrames. Every candle can carry the **hidden market regime** that produced it and a **bid-ask spread**, and every dataset comes back bit for bit from its seed and version.

## Your first dataset

```bash
pip install marketforge
marketforge generate -o ./data --from 2024-01-01 --days 90 --market crypto --with-regime --seed 42
```

That is 90 days of all 53 crypto instruments, every default timeframe from `m1` to `W1`, with the regime of every candle, the same on every run with seed 42. The same from Python:

```python
data = mf.generate("BTCUSD,ETHUSD", start="2024-01-01", days=30, seed=42, timeframes=["H1"], include_regime=True)
candles = data["BTCUSD"]["H1"]  # a pandas DataFrame: open, high, low, close, volume, regime
```

The [quick start](quick-start/) goes from here to Parquet, panels, tensors and extending a dataset.

## The five regimes

A market is always in one hidden state, shared by every instrument in it. With `--with-regime` (or `include_regime=True`) it is written next to each candle, in the `regime` column. The five colours of the MarketForge mark are these five regimes, in this order.

:::caution[Read this before you train anything]
Synthetic data teaches a model the generator, not the market. MarketForge has **no alpha to find**: it has the statistics of real markets and no edge that carries over to them. Use it to build, debug, pre-train and stress-test, and real data to decide whether anything earns money. See [What it is not](limits/).
:::
