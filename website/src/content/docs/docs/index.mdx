MarketForge generates **synthetic, statistically realistic market data**: minute-by-minute candles (`m1` to `W1`) for 208 crypto, forex and US stock instruments, on each market's real trading calendar, with optional **regime labels** and a **bid-ask spread**. Every dataset is bit-for-bit reproducible from a seed, and can be extended later without changing a single earlier candle.

It is built for the parts of quantitative work where real data is scarce, expensive, leaky or unlabelled:

- **Training and pre-training machine-learning models** on unlimited data with known ground truth (the hidden market regime of every minute).
- **Testing backtesters and trading systems** against calendars, gaps, closures, spreads and multi-asset alignment that behave like the real thing.
- **Stress testing** strategies on crashes, high-volatility regimes and flash crashes, as often as you want, with a different seed each time.

```bash
pip install marketforge
marketforge generate -o ./data --from 2024-01-01 --days 90 --market crypto --with-regime --seed 42
```

:::caution[Read this before you train anything]
Synthetic data teaches a model the generator, not the market. MarketForge has **no alpha to find**: it is a tool for building, debugging, pre-training and stress-testing, not a source of trading signals. See [What it is not](limits/).
:::
